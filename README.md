# Premium Portfolio

A modern, premium portfolio built with React, Vite, Tailwind CSS, Framer Motion, and a refined dark/light system.

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Project structure

- React + Vite app shell
- Tailwind CSS theme system
- Framer Motion animations
- Data-driven content via `src/data/data.js`
- Responsive portfolio sections with interactive project modal and contact form

## Environment

Copy `.env.example` to `.env` and add any required values.
